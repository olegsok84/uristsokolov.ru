# uristsokolov.ru

Статический лендинг для GitHub Pages по ТЗ от 23.05.2026.

## Что внутри

- `index.html` — главная страница из 11 блоков: главный экран, ситуации, услуги, риски, процесс, обо мне, кейсы, цены, квиз, FAQ, контакты.
- `styles.css` — адаптивный дизайн без внешних зависимостей.
- `script.js` — мобильное меню, cookie-баннер, квиз, валидация форм, подготовка payload для CRM/webhook.
- `privacy/` — страница политики персональных данных с местами для фактических реквизитов.
- `thank-you/` — страница благодарности.
- `404.html` — страница 404 для GitHub Pages.
- `robots.txt`, `sitemap.xml`, `CNAME` — базовая SEO-настройка.

## Что нужно заполнить перед полноценным запуском

1. Заменить/добавить реальные контакты в `index.html` и `window.SITE_CONFIG`:
   - телефон;
   - Telegram;
   - MAX;
   - email;
   - адрес офиса, если его нужно публиковать.
2. Добавить реальное фото вместо `assets/portrait-placeholder.svg` и изменить путь в главном экране.
3. Указать цены для проверки объекта и сопровождения сделки.
4. Подключить обработку форм:
   - CRM/webhook URL в `window.SITE_CONFIG.leadEndpoint`, или
   - внешний сервис форм, совместимый с GitHub Pages.
5. Подключить Яндекс Метрику и записать ID в `window.SITE_CONFIG.yandexMetrikaId`.
6. Уточнить и утвердить текст политики персональных данных: оператор, реквизиты, адрес, контакты, сервисы хранения документов.

## Публикация

Репозиторий настроен как GitHub Pages с доменом `uristsokolov.ru`. Достаточно закоммитить и запушить изменения в ветку `main`.
